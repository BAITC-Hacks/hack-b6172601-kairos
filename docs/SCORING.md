# Finance case scoring and acceptance

Source: official Money Graph task in docs/SPEC.md.

| Criterion | Points | Evidence to deliver |
|---|---:|---|
| Task compliance and working scenario | 25 | one-command batch, all nodes, 3 CSVs, searchable directed viewer |
| Technical implementation | 25 | defensible rules, reproducible clustering/ranking, real calculations |
| README and reproducibility | 25 | clean local/Docker run without API key, methods, checks, limitations |
| Value and applicability | 15 | clear priorities, numerical evidence, actionable investigation hypotheses |
| Development potential and originality | 10 | justified extensions and million-node scaling discussion |

Mandatory first: complete coverage, documented role rules, clustering, top >=20,
viewer and raw-to-output runtime <5 minutes. Exact schemas are in SPEC.md.
All result claims must be supported by actual runs. No accuracy claim without labels.
Optional temporal/LLM features must not delay mandatory delivery.

Final: fresh clone/build, no-key core, CSV validation, representative node review,
README and DISCLOSURE complete, no secrets, all progress pushed, platform solution
submitted separately from Git push. Respect official deadline even if it differs
from the five-hour calculation. No Fly changes until requested.
